# 坦克大战 Tank Battle

一个纯 HTML5 Canvas + JavaScript 实现的经典坦克大战小游戏，无需任何依赖，打开 `index.html` 即可游玩。

## 玩法

- **目标**：消灭所有敌方坦克，保卫底部的基地（红色旗帜）。
- 每过一关敌人数量增加，全部消灭后进入下一关（+500 分）。
- 被击毁损失一条生命，基地被摧毁或生命耗尽则游戏结束。
- 砖块可以被子弹打穿，钢块无法摧毁。

## 操作

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → / W A S D | 移动坦克 |
| 空格 / J | 射击 |
| P | 暂停 / 继续 |

## 本地运行

直接用浏览器打开 `index.html` 即可，或启动一个本地服务器：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后访问 http://localhost:8000

## 技术说明

- 单文件实现（`index.html`），零依赖
- Canvas 渲染，requestAnimationFrame 游戏主循环
- 敌方坦克 AI：随机巡逻 + 概率性瞄准玩家/基地
- 支持子弹对撞、出生护盾、爆炸特效
